# Formatting Standards

- Follow the repository's established formatting configuration and conventions.
- Default Java style: 4-space indentation, UTF-8, consistent braces, descriptive names and imports without wildcards.
- Do not reformat unrelated files or create large whitespace-only diffs.
- If Spotless/Checkstyle or another formatter is configured, use its documented Maven goal.
- Do not install or modify formatter plugins without approval.
- Use a final newline and avoid trailing whitespace in text files.
